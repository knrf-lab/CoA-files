SIDE B · THEORY & FORMULAS look up the T# from the front

T1 Hex ↔ binary · bytes

0 00004 01008 1000C 1100
1 00015 01019 1001D 1101
2 00106 0110A 1010E 1110
3 00117 0111B 1011F 1111

1 hex digit = 4 bits · 1 byte = 2 hex digits. 32-bit = 4 bytes: MSB = leftmost pair, LSB = rightmost. Bin → hex: group 4 from the right. Bits → decimal: Σ bit × 2^position (…128 64 32 16 8 4 2 1). ASCII: 7 bits in 1 byte ('A' 41, 'a' 61, '0' 30); same bits can be text, number or instruction.

T2 Two's complement (n bits)

Range −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1 (8-bit −128…127 · 16-bit −32768…32767). Unsigned: 0 … 2ⁿ − 1.
Sign: MSB 0 → +, MSB 1 → −. Hex: first digit 0–7 → +, 8–F → −.
Negate: write +value, flip all bits, add 1 (−10: 00001010 → 11110101 → 11110110).
Decode a negative: value = unsigned − 2ⁿ (0xF6 = 246 − 256 = −10).

T3 Moore's Law · CPU performance

Factor = 2^(years ÷ doubling period). Time ∝ 1/performance: older CPU → time × factor; newer → time ÷ factor.
CPU time = IC × CPI ÷ f = IC × CPI × T · cycles = IC × CPI · f = 1/T (1 GHz ↔ 1 ns, 2 GHz ↔ 0.5 ns) · Speedup = old time ÷ new time.

T5 Fetch–decode–execute (RTN)

FetchMAR ← PC · MBR ← M[MAR] · IR ← MBR · PC ← PC + 1
Decodeopcode = IR[15–12] · MAR ← IR[11–0]

Memory is always reached through MAR (address) and MBR (data). PC already points to the next instruction during execute.

T6 Assembling a MARIE program

1. Symbol table (pass 1): every label → its address. 2. Hex (pass 2): opcode digit + 3-digit address of the operand label. No operand (Input, Output, Halt) → 000. Skipcond keeps its condition (8000/8400/8800). DEC/HEX lines are data (DEC 60 = 003C).
3. Trace: track AC, PC and memory written by Store. Jump/Skipcond change PC.

T7 Expanding opcodes

Pattern count (prof's method): each instruction uses 2^(operand bits) patterns.
Σ count × 2^(operand bits) ≤ 2^(instruction bits) → possible.
Escape check: opcode bits = instr bits − operand bits. Group 1 gets 2^(opcode bits) codes; leftover codes × 2^(extra opcode bits) feed the next group. Leftover 0 too early → impossible.

T8 Pipelining

k stages, n instr, τ cycle, tn non-pipelined instr time (= kτ if equal stages).
Pipelined = (k + n − 1)·τ (+ s stalls: (k + n − 1 + s)·τ) · Non-pipelined = n·tn · S = n·tn ÷ ((k+n−1)·τ) → k as n grows.
Hazards: structural (same hardware) · data (result not ready → forwarding) · control (branch → flush/prediction).

T9 Address bits

bits = log₂(# addressable units). Word-addressable: units = # words. Byte-addressable: units = words × (bits per word ÷ 8).
2¹⁰ 1K · 2¹² 4K · 2¹⁶ 64K · 2²⁰ 1M · 2²² 4M · 2²³ 8M · 2²⁴ 16M · 2²⁵ 32M · 2³⁰ 1G

T10 Cache address fields

Address = Tag | Index (or Set) | Offset, split from the right.
Offset = log₂(block bytes) · Index = log₂(# lines) · Set bits = log₂(lines ÷ N) for N-way · Fully associative: no index · Tag = remaining bits.
# memory blocks = memory ÷ block size · block # = ⌊addr ÷ block⌋ · line = block mod lines · set = block mod sets.

T11 Cache tracing · replacement · writes

Direct: line = block mod lines; new block always replaces the old one. Set assoc.: set = block mod sets, any line in the set. Fully: any line.
Hit = block already there. Hit rate = hits ÷ accesses.
LRU: evict least recently used (a hit refreshes it). FIFO: evict oldest loaded (hits change nothing). LFU: fewest uses. Same result unless a hit happens before an eviction.
Write-through: cache + memory every write (consistent, more traffic). Write-back: cache only + dirty bit, memory written on replacement.

T12 Endianness

Big: MSB at lowest address (write bytes left → right). Little: LSB at lowest address (reverse the bytes). Pad to full width first (0x1234 as 32-bit = 00 00 12 34). Bits inside a byte never change.
Big: UNIX, MIPS, network order. Little: Intel x86. Bi-endian: MIPS, ARM.

T13 Addressing modes

Immediate: operand in the instruction · Direct: EA = A → M[A] · Register: in a register · Indirect: EA = M[A] → M[M[A]] · Indexed: EA = A + index reg → M[EA] · Array: base + i × element size.

T14 Instruction formats · postfix

Postfix (RPN): operands then operator; (A+B)×C → A B + C ×. Stack (0-addr) · Accumulator (1-addr, MARIE) · GPR (2/3-addr).
3-addr: OP dest,src1,src2 · 2-addr: OP dest,src (dest = dest OP src) · 1-addr: OP X uses AC. Fixed length = fast decode; variable = compact.

C Concepts for short-answer questions

  • Architecture = what the programmer sees (ISA, registers, data types, addressing). Organization = how it's built (control signals, buses, memory tech).
  • Von Neumann: stored program, CPU + memory + I/O, one shared CPU–memory path = bottleneck. Harvard: separate instruction/data paths.
  • Bus: data · address · control lines. CPU = datapath (registers, ALU) + control unit. Hardwired control fast/rigid; microprogrammed flexible/slower.
  • CISC: many complex variable-length instr (x86). RISC: few simple fixed-length, load/store (MIPS, ARM).
  • Hierarchy registers → cache → RAM → disk: capacity ↑, cost/bit ↓, latency ↑ going down. Goal: near-fastest speed at near-cheapest cost.
  • SRAM flip-flop, fast, cache. DRAM capacitor, refresh, main memory. Temporal locality: reuse soon; spatial: neighbours soon.
  • Virtual memory: page table/MMU maps virtual → physical; page fault = page on disk; TLB caches page-table entries.
  • 2 driving factors of computer development: cost and performance. Moore's limits: atom size, heat, cost.
