Cheat sheet: T4 T5 T6 · Used in: Q4, Q5, P4, P5

MARIE = Machine Architecture that is Really Intuitive and Easy. It is a teaching computer small enough to trace by hand. If you understand MARIE, you understand how every CPU runs a program.

Architecture and registers

• Stored-program, fixed word length, word-addressable, accumulator-based.
• 4K words of memory = 2¹² → 12-bit addresses (000 … FFF hex).
• 16-bit data words and 16-bit instructions.
• Two's-complement integers.
• Seven registers (table).

Why is MAR 12 bits but AC 16 bits? S2-3 exercise 3

MAR holds an address. There are 2¹² locations, so 12 bits are enough to name any of them. AC holds data: a full 16-bit memory word. Addresses and data have different sizes, so their registers do too. (PC also holds an address → 12 bits; MBR and IR hold whole words → 16 bits.)
RegBitsHolds
AC16Accumulator: data values and arithmetic results
MAR12Memory Address Register: the address to read/write
MBR16Memory Buffer Register: data just read from, or about to be written to, memory
PC12Program Counter: address of the next instruction
IR16Instruction Register: the instruction now being executed
InREG8Input from the keyboard
OutREG8Output to the display
✔ The CPU never touches memory directly. Every read goes memory → MBR, and every write goes MBR → memory, at the address in MAR.

Register Transfer Notation (RTN)

One instruction is really several tiny steps (micro-operations). RTN writes each as "destination ← source".

InstrRTNALU?
Load XMAR ← X · MBR ← M[MAR] · AC ← MBRno
Store XMAR ← X · MBR ← AC · M[MAR] ← MBRno
Add XMAR ← X · MBR ← M[MAR] · AC ← AC + MBRyes
Subt XMAR ← X · MBR ← M[MAR] · AC ← AC − MBRyes
InputAC ← InREGno
OutputOutREG ← ACno
Jump XPC ← Xno
▣ METHOD For any instruction ask three questions (Study Guide p.5):
1. Where does the address go? → MAR.
2. Where does the data go? → through MBR, to/from AC.
3. Is the ALU needed? → only for Add and Subt.

Load: the data flows X → MAR → M[MAR] → MBR → AC (the slide's flow diagram). Store runs the opposite way: AC → MBR → M[MAR].

The fetch–decode–execute cycle

StageRTNIn words
FetchMAR ← PCput the next instruction's address on the bus
MBR ← M[MAR]read that instruction from memory
IR ← MBRkeep it in IR
PC ← PC + 1point PC at the following instruction

At the start of each cycle the CPU checks for an interrupt (an event that changes the normal flow).

Worked example quiz Q4, prof's solution

PC = 150, M[150] = 4155, M[155] = 0010, AC = 0035.
1. Decode 4155: opcode 4 (Subt), operand address 155.
2. Fetch: MAR ← PC (150) · MBR ← M[MAR] (4155) · IR ← MBR (4155) · PC ← PC + 1 (151)
3. Execute Subt 155: MAR ← IR[11–0] (155) · MBR ← M[MAR] (0010) · AC ← AC − MBR
Final AC = 0035 − 0010 = 0025 (hex)

Worked example cheat sheet P4

PC = 200, M[200] = 320A, M[20A] = 0007, AC = 0012.
Decode: Add 20A. Fetch: MAR ← 200, MBR ← 320A, IR ← 320A, PC ← 201. Execute: MAR ← 20A, MBR ← 0007, AC ← 0012 + 0007 = 0019, PC = 201
⚠ TRAP PC is incremented during fetch, so during execute it already points to the next instruction (151, not 150). A Jump simply overwrites it.

Skipcond and Jump: decisions and loops

Skipcond (opcode 8) tests the AC. Bits 11–10 of the instruction pick the test:
8000: skip if AC < 0 · 8400: skip if AC = 0 · 8800: skip if AC > 0
"Skip" means PC ← PC + 1, so the next instruction is jumped over.
Jump X (opcode 9): PC ← X.

If/else pattern: compute A − B, Skipcond on the result, put a Jump to the "else" part right after it.

Assemblers and the symbol table

An assembler translates assembly (mnemonics + labels) into machine code. Labels are names for addresses, so the assembler needs two passes:

▣ METHOD: assemble a MARIE program
Pass 1 — symbol table: walk the listing, note every label and its address (label → address).
Pass 2 — machine code: for each line, write opcode digit + the 3-digit address of its operand (looked up in the symbol table).
• No operand (Input, Output, Halt) → address 000.
• Skipcond keeps its condition: 8000 / 8400 / 8800.
• DEC n / HEX n lines are data: write the value as 4 hex digits (DEC 60 = 003C, HEX 0000 = 0000).
