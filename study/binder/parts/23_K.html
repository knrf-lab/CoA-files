2. Two's complement →
(a) Unsigned 15·4096 + 15·256 + 13·16 + 6 = 65,494. First digit F → negative: 65,494 − 65,536 = −42
(b) +100 = 0110 0100 → flip 1001 1011 → +1 → 1001 1100 = 0x9C (check: 156 − 256 = −100 ✓)
(c) −2¹¹ … 2¹¹ − 1 = −2048 … 2047
3. Characters and bytes → ,
(a) 0x4849 = 0100 1000 0100 1001. Leftmost bit 0 → positive (+18,505)
(b) Bytes 12 | AB | 34 | CD → MSB 0x12, LSB 0xCD, middle bytes 0xAB34
4. Endianness →
(a) −2 in 32 bits = 0xFFFFFFFE. Big: FF FF FF FE. Little: FE FF FF FF
(b) Big endian reads left to right: 0x0000012C = 1·256 + 2·16 + 12 = 300
5. Moore's Law →
18 months = 1.5 years. (a) 3 ÷ 1.5 = 2 doublings → 4× slower → 10 × 4 = 40 s. (b) 4.5 ÷ 1.5 = 3 → 8× faster → 10 ÷ 8 = 1.25 s
6. Address bits → ,
(a) 64K = 2¹⁶ words → 16 bits. (b) 64K × 2 bytes = 128K = 2¹⁷ → 17 bits. (c) PC holds an address. MARIE has 4K = 2¹² words, so 12 bits are enough to address every word.
7. MARIE fetch–decode–execute →
(a) 20B4 → opcode 2 = Store 0B4
(b) MAR ← PC (0A0) · MBR ← M[MAR] (20B4) · IR ← MBR (20B4) · PC ← PC + 1 (0A1)
(c) MAR ← IR[11–0] (0B4) · MBR ← AC (0123) · M[MAR] ← MBR. Final: AC = 0123, M[0B4] = 0123, PC = 0A1 (Store doesn't change AC; the old FFFF is overwritten.)

(a) ((A × (B + C)) − (D / E)) → A B C + × D E / −
(b) push 6 · push 2 · push 3 · + → 6 5 · × → 30 · push 4 · − → 26

11. Addressing modes →

12. Pipelining → ,
Non-pipelined = 500 × 90 = 45,000 ns. Pipelined = (6 + 500 − 1) × 15 = 7,575 ns.
(a) S = 45,000 ÷ 7,575 = 5.94 (b) k = 6 (c) (505 + 20) × 15 = 7,875 → S = 5.71
(d) Data hazard (SUB needs R1 before ADD has written it). Fix: forwarding/bypassing, or stall.
13. CPU time →
A: 2×10⁹ × 1.5 ÷ 3×10⁹ = 1.0 s. B: 2×10⁹ × 1.2 ÷ 2.4×10⁹ = 1.0 s. Speedup = 1. A's faster clock is cancelled by its higher CPI: clock rate alone does not decide performance.
14. Cache address fields →
(a) 2²⁰ ÷ 2⁵ = 2¹⁵ = 32,768 blocks
(b) 20-bit address: offset log₂32 = 5, index log₂256 = 8, tag 20 − 8 − 5 = 7 → Tag 7 | Index 8 | Offset 5.
0xABCDE = 1010 1011 1100 1101 1110 → 1010101 | 11100110 | 11110 → block 230 (0xE6), tag 85, offset 30
(c) 256 ÷ 4 = 64 sets → set 6 bits, tag 9 → Tag 9 | Set 6 | Offset 5. 101010111 | 100110 | 11110 → set 38, tag 343
15. Cache tracing → ,
(a) Direct: lines (mod 4) 0, 0, 0, 0, 0, 1, 1, 1 → M M M M M M M M → 0 hits (0, 4, 8 keep evicting each other in line 0; 1 and 5 do the same in line 1)
(b) 2-way: 2 sets (mod 2). Set 0 gets 0, 4, 8, 0, 4: M M M (evicts 0) M (evicts 4) M (evicts 8). Set 1 gets 1, 5, 1: M M H → 1 hit
(c) Fully associative: 0 M · 4 M · 8 M · 0 H · 4 H · 1 M (cache full: 0, 4, 8, 1) · 5 M evicts LRU block 8 · 1 H → 3 hits
More flexibility in placement → fewer conflict misses.
16. Effective access time →
(a) 0.95 × 5 + 0.05 × 80 = 4.75 + 4 = 8.75 ns
(b) 6 = 5H + 80(1 − H) = 80 − 75H → H = 74/75 = 0.9867 (98.7%)
17. Write policies and locality → ,
(a) Write-through 50 writes; write-back 0 while cached, 1 when the block is evicted. (b) It marks a block modified in the cache, so it is written back to memory on replacement. (c) Spatial (neighbouring elements) and temporal (the sum variable and loop instructions are reused).
18. Concepts → , ,
(a) Registers: architecture. SRAM cache: organization. Instruction format: architecture. Bus clock speed: organization.
(b) Instructions and data share one memory and one CPU–memory path, so they compete for it. Harvard uses separate memories/paths for instructions and data.
(c) Hardwired: logic gates, fast, hard to change. Microprogrammed: microcode, flexible, slower.
19. Virtual memory →
(a) Offset log₂1024 = 10 bits, page number 16 − 10 = 6 bits
(b) 0x1C3A = 000111 | 0000111010 → page 7, offset 0x03A → frame 2 | 0x03A = 0x083A
(c) Page fault: the OS loads the page from disk into a frame, updates the page table, and the access is retried.
