Exam traps

  • MSB = bit or byte? Q1 means byte, Q2 means bit. Read the sentence.
  • Older vs newer (Moore): older → multiply the time, newer → divide.
  • Address vs contents: X is an address, M[X] is what's stored there.
  • Hex arithmetic in MARIE: 0035 − 0010 = 0025 hex, which is 37 decimal.
  • DEC vs HEX directives: "DEC 60" is stored as 003C; "HEX 60" is 0060.
  • No-operand instructions get address 000: Output = 6000, Halt = 7000.
  • Skipcond codes: 000 → AC < 0, 400 → AC = 0, 800 → AC > 0. It skips the next line only.
  • PC during execute already points to the next instruction.
  • Fetch has 4 transfers: don't forget PC ← PC + 1, and don't skip the MBR.
  • Execute starts with MAR ← IR[11–0] (the prof's form), not MAR ← X, once the instruction is in IR.
  • Pipeline formula is (k + n − 1)·τ, not k·n·τ. The non-pipelined time uses tn = k·τ.
  • Expanding opcodes: multiply each count by 2^(total operand bits) (three 4-bit operands = 2¹²).
  • 4M × 16 byte-addressable: × 2 bytes per word → 8M → 23 bits.
  • Cache fields are split from the right; the tag is whatever is left.
  • Set-associative index = log₂(sets), sets = lines ÷ N.
  • Direct mapped has no replacement policy: the line is fixed.
  • FIFO ignores hits; LRU refreshes on every hit.
  • Write-back uses the dirty bit; write-through doesn't need one.
  • Two's complement sign: a hex first digit 8–F means negative (16-bit).
  • Endianness: pad 0x1234 to 00001234 before storing it as 32-bit.
  • K/M/G are powers of 2 for memory, powers of 10 for Hz and seconds.
