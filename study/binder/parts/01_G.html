G · Glossary: acronyms, registers, question words

Most marks lost on "easy" questions come from misreading one word. The words that change the method are marked ★.

Acronyms and register names

TermMeansPage
ACAccumulator: MARIE's only data register; holds operands and results
MARMemory Address Register: the address being read/written
MBRMemory Buffer Register: the data going to/from memory
PCProgram Counter: address of the next instruction
IRInstruction Register: the instruction being executed now
InREG / OutREGInput / output registers (8 bits)
ALUArithmetic Logic Unit: does add, subtract, AND, OR, compare
CUControl Unit: decodes instructions, sends control signals
ISAInstruction Set Architecture: the instructions a CPU understands and their formats
RTN / RTLRegister Transfer Notation/Language: "MAR ← PC" style micro-steps
M[X]The contents of memory address X (X itself is just the address)
IR[15–12]Bits 15 down to 12 of IR (the opcode)
★ MSB / LSBMost / least significant bit or byte. Read the context! Q1 means byte, Q2 means bit.
EAEffective address: where the operand actually is
RPNReverse Polish notation = postfix (A B +)
GPRGeneral-purpose register architecture
CISC / RISCComplex / reduced instruction set computer
IC, CPIInstruction count; cycles per instruction
k, n, τ, tnPipeline stages, instructions, cycle time, non-pipelined time per instruction
SRAM / DRAMStatic RAM (flip-flops, cache) / dynamic RAM (capacitors, main memory)
LRU / FIFO / LFULeast recently used / first in first out / least frequently used
MMU, TLBMemory management unit; translation look-aside buffer (cache of page-table entries)
VLSI, ICVery-large-scale integration; integrated circuit (in history)
SaaS/PaaS/IaaSSoftware / Platform / Infrastructure as a Service
