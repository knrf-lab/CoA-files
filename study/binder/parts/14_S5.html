Design decisions

An ISA designer balances: how much memory programs take, how complex decoding is, how long instructions are, and how many instructions there are. Short instructions take less memory and are fetched faster, but leave fewer bits for opcodes and operands.

  • Instruction length: fixed (fast to decode, may waste space) or variable (compact, harder to decode).
  • Number of operands per instruction: 0, 1, 2 or 3.
  • Operand location: immediate (in the instruction), register, or memory.
  • Addressing modes () and byte order ().

Postfix (reverse Polish) and stack machines

Infix puts the operator between operands (2 + 3). Postfix (RPN) puts it after (2 3 +). Postfix needs no parentheses and is exactly how a stack machine works.

▣ METHOD: infix → postfix
1. Fully bracket by precedence (× ÷ before + −, left to right).
2. Inside each bracket write: left operand, right operand, operator.
3. Work from the innermost bracket out.

Expanding opcodes

With a fixed instruction length, instructions with more operand bits have fewer opcode bits left. Expanding opcodes give a short opcode to instructions with many operands and longer opcodes to those with few. Unused short opcodes act as escape opcodes: they say "the opcode continues into the next field".

Prof's method (pattern count)
An instruction with b operand bits uses 2ᵇ bit patterns (one for every operand value).
Possible ⇔ Σ (count × 2^(operand bits)) ≤ 2^(instruction bits)
Escape method (constructive check)
1. First group: opcode bits = instruction bits − its operand bits → 2^(opcode bits) codes. Use what you need.
2. Leftover codes × 2^(extra opcode bits) = codes for the next group.
3. Repeat. If any group gets fewer codes than it needs → impossible.

Worked example quiz Q6, prof's solution

16-bit; 5 instr with three 4-bit operands, 30 with two 5-bit, 50 with one 8-bit.
5 × 2⁴ × 2⁴ × 2⁴ = 5 × 2¹² = 20,480
30 × 2⁵ × 2⁵ = 30 × 2¹⁰ = 30,720
50 × 2⁸ = 12,800
Total 64,000 ≤ 2¹⁶ = 65,536 → possible (1,536 patterns unused)
Escape check: 4-bit opcode → 16, use 5 → 11 left. 11 × 2² = 44 ≥ 30 → 14 left. 14 × 2² = 56 ≥ 50 ✓

Example S4-5 exercise 3

11-bit, 4-bit address fields; 5 two-address, 45 one-address, 32 zero-address.
5·2⁸ + 45·2⁴ + 32 = 1280 + 720 + 32 = 2032 ≤ 2¹¹ = 2048 → yes

12-bit, 4-bit fields; 14 two-address, 32 one-address, 16 zero-address.
14·2⁸ + 32·2⁴ + 16 = 3584 + 512 + 16 = 4112 > 4096 → not possible. Escape: 2 left → 32, all used → 0 for zero-address.

Arrays: EA = base + index × element size (element 5 of an array of 4-byte ints at 2000 → 2000 + 20 = 2020).

Direct vs indirect (S4-5 exercise 4): direct gives the operand's address in the instruction; indirect gives the address of a location that holds the operand's address. LOAD 100 direct → loads M[100]. LOAD 100 indirect → if M[100] = 250, loads M[250].
