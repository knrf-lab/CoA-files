[5]1. (a) Convert 0x3C7 to binary and to decimal. (b) Convert 200 to 8-bit binary and to hex. (c) Compute 0x2A + 0x3C in hex.
[6]2. (a) The 16-bit pattern 0xFFD6 is read as an unsigned integer and as a two's-complement integer. Give both values. (b) Write −100 in 8-bit two's complement (binary and hex). (c) What is the range of a 12-bit two's-complement integer?
[5]3. (a) The string "HI" is packed into one 16-bit word ('H' = 0x48, 'I' = 0x49). Write the word in hex and binary. Read as two's complement, is it positive or negative? (b) For the 32-bit value 0x12AB34CD, give the most significant byte, the least significant byte, and the 16-bit code formed by the two middle bytes.
[5]4. (a) The 32-bit integer −2 is stored at address 0x100. Show the bytes at 0x100–0x103 on a big-endian and on a little-endian machine. (b) A big-endian machine holds 00 00 01 2C at addresses 0x200–0x203. What decimal value is stored there?
[4]5. A program runs in 10 s on today's processor. Performance doubles every 18 months. How long does it take on a processor (a) 3 years older, (b) 4.5 years newer?
[4]6. A memory is organized as 64K × 16. How many address bits are needed if it is (a) word-addressable, (b) byte-addressable? (c) Explain why MARIE's PC is 12 bits wide.
[7]7. A MARIE computer has PC = 0A0, M[0A0] = 20B4, M[0B4] = FFFF and AC = 0123 (all hex). (a) Decode the instruction. (b) Show the fetch-cycle register transfers. (c) Show the execute-cycle transfers and give the final AC, M[0B4] and PC.

(a) Build the symbol table. (b) Give the hex code for addresses 100–10C. (c) Trace the program and give the output. (d) What is the output if Y is DEC 5 instead? What does the program do?
[6]9. A computer has 16-bit instructions and 4-bit address fields. Is it possible to encode, using expanding opcodes, 13 three-address, 40 two-address, 50 one-address and 16 zero-address instructions? Prove it by counting bit patterns, then confirm with the escape-opcode method.
[5]10. (a) Convert A × (B + C) − D / E to postfix. (b) Evaluate the postfix expression 6 2 3 + × 4 −, showing the stack. (c) Write stack-machine (0-address) code for Z = (A + B) × C.
[4]11. The instruction is LOAD 200. Memory holds M[200] = 350, M[350] = 410, M[600] = 725, and the index register R1 = 400. What value is loaded with immediate, direct, indirect and indexed addressing?
[6]12. A non-pipelined processor takes 90 ns per instruction. A 6-stage pipeline with a 15 ns clock runs the same 500 instructions. (a) Speedup? (b) Maximum possible speedup? (c) Speedup if hazards add 20 stall cycles? (d) Name the hazard caused by "ADD R1, R2, R3" followed by "SUB R4, R1, R5" and one fix.
[4]13. A program executes 2 × 10⁹ instructions. CPU A has CPI 1.5 at 3 GHz; CPU B has CPI 1.2 at 2.4 GHz. Compute both CPU times and the speedup of A over B. What does this show about clock rate?
[7]14. A byte-addressable memory has 2²⁰ bytes. The cache has 256 blocks of 32 bytes. (a) How many blocks of main memory are there? (b) Direct mapped: give the address format and the cache block of address 0xABCDE. (c) 4-way set associative: give the address format and the set of 0xABCDE.
[6]15. A cache has 4 blocks. The block references are 0, 4, 8, 0, 4, 1, 5, 1. Show hit/miss for each and the number of hits if the cache is (a) direct mapped, (b) 2-way set associative with LRU, (c) fully associative with LRU. Explain the difference.
[4]16. Cache access time is 5 ns and main memory access time is 80 ns. (a) Effective access time at a 95% hit rate? (b) What hit rate gives an effective access time of 6 ns?
[5]17. (a) A program updates the same variable 50 times while it stays in the cache. How many main-memory writes happen under write-through and under write-back? (b) What is the dirty bit for? (c) A loop sums the elements of an array. Which kinds of locality does it show?
