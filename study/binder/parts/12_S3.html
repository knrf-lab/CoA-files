Inside the CPU

The CPU fetches instructions, decodes them and performs the operations on the right data. It has two parts:

  • Datapath: the network of registers, the ALU, and the internal buses that move and process data.
  • Control unit: the "traffic manager / policeman". It fetches and decodes instructions and sends control signals so the right data is in the right place at the right time.
  • Registers: the fastest storage, inside the CPU. Some are special-purpose (PC, IR, MAR, MBR), some general-purpose.
  • ALU: does arithmetic (add, subtract, multiply) and logic (AND, OR, compare). It is part of the CPU and is driven by signals from the control unit (S2-3 exercise 1).

The bus

A bus is a shared set of wires connecting subsystems; it moves bits in parallel. A system bus has three kinds of lines:

LinesCarry
Datathe actual information being moved
Addressthe memory or I/O location being accessed
ControlREAD / WRITE, timing, which device may use the bus
✔ Link to MARIE: the address lines are fed by MAR, the data lines by MBR. The width of the address bus decides how many locations can be reached: 12 address lines → 2¹² = 4096 = 4K, which is MARIE's memory size.

The clock

The clock synchronizes every component. One instruction takes a fixed number of clock cycles.
f = 1 / T and T = 1 / f (f = clock rate in Hz, T = cycle time in s)
1 GHz = 10⁹ Hz ↔ T = 1 ns · 2 GHz ↔ 0.5 ns · 500 MHz ↔ 2 ns

A faster clock does not guarantee a faster program: the cycle must be long enough for signals to cross the circuits, and the number of cycles per instruction also matters (Tab 6).

Example: clock arithmetic

A 2.5 GHz CPU: T = 1 ÷ (2.5 × 10⁹) = 0.4 × 10⁻⁹ s = 0.4 ns.
An instruction needing 5 cycles takes 5 × 0.4 = 2 ns.
A 4.20 GHz CPU: T = 1/4.2 ≈ 0.238 ns.

Memory organization and address bits

Memory is a grid of bits: each row (location) has a unique address. A memory written A × B has A locations each B bits wide (e.g. 4M × 16).

  • Byte-addressable: every byte has its own address (most common today).
  • Word-addressable: every word has its own address (MARIE).
Address bits = log₂(number of addressable units) (round up if not a power of 2)
Word-addressable: units = number of words (A).
Byte-addressable: units = A × (B ÷ 8).
The number of bits depends on how many units, not on their size.

Example: 2M × 32, word-addressable S2-3 exercise 2

Units = 2M = 2 × 2²⁰ = 2²¹ → 21 bits

Example: 4M × 16, byte-addressable S6-7 exercise 2

16 bits = 2 bytes per word. Units = 4M × 2 = 8M = 2²³ → 23 bits

Example: 8M × 32 both ways cheat sheet P9

Word: 8M = 2²³ → 23. Byte: 8M × 4 = 32M = 2²⁵ → 25

Example: MARIE

4K × 16, word-addressable: 4K = 2¹² → 12 bits. That is why MARIE's MAR and PC are 12 bits wide.
⚠ TRAP In "4M × 16", the 16 is the word width in bits. Divide by 8 to get bytes per word before multiplying for a byte-addressable memory.
